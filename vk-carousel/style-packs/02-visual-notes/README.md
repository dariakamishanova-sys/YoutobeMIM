Рабочий паспорт, выбран редактором 01.11.2026. Это отдельное направление, не изменение «Фото и уведомлений».

## Правила

- Ручной шрифт выбранного образца, крупные уверенные буквы, читаемые на телефоне. Не заменять обычным тонким шрифтом.
- Белый фон, едва заметная точечная сетка, живая чёрная линия, минимум деталей. Основной акцент жёлтый. Артём — отдельная утверждённая ярко-фиолетовая версия (#8B3DFF); на плотной фиолетовой подложке белый текст.
- Основной язык — схемы, списки, группировка, связи и записи. Не уходить в комикс или подробную бытовую иллюстрацию. Персонаж появляется выборочно.
- Чередовать плотность и функцию слайдов: титульная запись, схема, вопрос, пример, разбор. Не повторять на каждом заголовок + мелкие объекты + персонаж. В парах проблема/решение можно сознательно повторить основу рисунка с содержательным изменением.
- Воздух не заполняется декоративными значками. Не делать случайные огромные пустоты, дробящие композицию.
- Сценарий явно разделяет ВСЕ надписи и инструкции к визуалу. Надписи схемы не дублируются соседним абзацем.
- Один интерактивный выбор на карусель, если не задано иначе. У Веры это карточка3 с четырьмя ячейками А/Б/В/Г; карточка2 только ситуация. Вопросы в дальнейшем разборе не новые голосования.
- У CTA соответствующая иконка: комментарий, Telegram, сохранение и т.д. Видимые метки «Ошибка»/«Решение» без номеров — только в календаре Артёма, не у Веры.
- Персонажи и устройства без видимых жёстких внутренних обрезов. На всех карточках номер, «Мастерская инженеров менеджеров», system-school.ru.
- Отдельная папка PNG 01–NN, без PDF/ZIP; рядом сценарий, промпты, оригиналы, технический манифест. Текст текущих генераций встроен в растр: не объявлять их редактируемыми текстовыми слоями. Локальные правки выполнять по соответствующему изображению.

## Обязательные проверки

Чистая кожа без сетки и повторяющихся искусственных текстур; неизменная идентичность; собственные жесты каждого героя; смена крупности по сюжету; отсутствие повторов текста между интерфейсом и повествованием; физически корректные устройства.

## Метод

Оценить источники по дате и применимости; выбрать три приоритетных портрета; для каждого выпуска выделить одного читателя, ситуацию, затруднение и следующий шаг; приоритизировать темы по пользе и доступности достоверного материала.

## Рабочий продукт

Заполненный бриф: три выбранных приоритетных портрета, у каждой темы один адресат и одна основная ситуация, цель первого выпуска, три темы с тезисом, источником и ограничениями.

## Критерии приёмки

- [x] Из пяти кандидатов редактором выбраны три приоритетных портрета: «Занятые», «Инициаторы», «Проверяющие».
- [ ] После уточнения затруднений для каждого будущего выпуска описан один конкретный читатель. Варианты «все интересующиеся» не приняты.
- [ ] Для первого выпуска выбраны одна рабочая ситуация, выполнимое действие после поста и наблюдаемый результат. Предварительные варианты в очереди не заменяют этого выбора.
- [ ] Выбраны ровно три темы, у каждой есть свежий источник и главный тезис.
- [ ] Пробелы и допущения видны; показатели внешних кейсов не выданы за прогноз МИМ.
- [ ] Редактор подтвердил выбор; критерии передачи записаны в бриф.

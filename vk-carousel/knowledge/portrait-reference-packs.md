# Где смотреть фотопаки персонажей и мимики
Подборка для каруселей МИМ · проверено 27 октября 2026

## Два полезных направления
- Готовые фотографические персонажи на прозрачном фоне: искать **photo characters**, **cutout people**, **character photo pack**. Подходит для сравнения состава нашего пака: один человек, разные позы, действия и реквизит.
- Фотографические референсы выражений: **facial expression reference pack**, **same model expressions**, **portrait reference pack**. Подходит для изучения глаз, губ, щёк, ракурсов и диапазона эмоций.

## Поисковые запросы

| Что нужно | Запрос |
|---|---|
| Пак фото одного героя | `same model portrait reference pack` |
| Мимика одного человека | `same person facial expression reference pack` |
| Портреты среднего возраста | `middle aged man facial expressions reference pack` |
| Сдержанная мимика | `subtle facial expressions male photo reference` |
| Задумчивый характер | `pensive weary melancholic man portrait reference` |
| Разные ракурсы | `character turnaround photo reference front profile three quarter` |
| Вырезанные фигуры для карточек | `cutout people multiple poses expressions transparent PNG` |
| Деловые персонажи | `business photo character pack same person` |

Русские варианты: «референсы мимики одного человека», «фотопак эмоций мужчины», «один человек разные эмоции референсы», «фотоперсонаж PNG разные позы».

Слово `portrait pack` само по себе может дать просто разных людей. Добавляйте `same model` или `same person`. Для фотографий добавляйте `photo` или `photographic`; для обзоров листами — `expression sheet` или `contact sheet`.

Превью на этих страницах используются как примеры структуры и диапазона выражений. В этой задаче паки не приобретались и изображения из них не включались в наши исходники.

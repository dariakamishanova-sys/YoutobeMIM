# Елена v4 · редактируемые мастер-макеты

7 SVG соответствуют 01.png–07.png. Открывать в Inkscape или другом SVG-редакторе с поддержкой текста и встроенных PNG. Гарнитура — Open Sans Regular/Bold; для одинакового отображения её нужно установить. Публиковать PNG из папки карусели, не эти исходники.

Слои с именами: background, photo (на карточках с героиней), headline, body-text, interfaces, marker-symbols, footer; на 7-й — cta. Текст остаётся текстом, а не кривыми. Фото встроено в SVG и сохранено отдельно как фотооснова. На 2-й и 4-й фотографии нет. Все сообщения, счётчики, значки, экраны и маркерные символы собраны отдельно; кожа и физические предметы внутри фото остаются растровыми.

Правка текста/цвета не требует регенерации фото. Лицо/предмет исправляются локально по маске; ошибка композиции — пересборкой. После изменения проверить границы и экспорт. При замене фото сверить экранные наложения на 5-й и 6-й: их положение связано с перспективой устройства.
